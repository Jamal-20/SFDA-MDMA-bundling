🔬 SFDA MDMA Bundling Decision Flowchart

Medical Devices & IVD Medical Devices
📌 Reference: SFDA MDS-G-028-V1 (2026) 
flowchart TD
    START["START: Device list for MDMA application"]
    START --> TYPE{Device category?}
    
    TYPE -->|Medical Devices| MED_START
    TYPE -->|IVD Medical Devices| IVD_START
    
    MED_START[Medical Devices Pathway] --> M1{Same legal manufacturer?}
    M1 -->|NO| SEPARATE["Submit separate applications"]
    M1 -->|YES| M2{Procedure Pack?}
    
    M2 -->|YES| PACK["PROCEDURE PACK
Same intended use + specialty
Max 5 TFs, Max 50 items
Letter of agreement required"]
    M2 -->|NO| M3{System? Used together}
    
    M3 -->|YES| SYSTEM["SYSTEM
Same manufacturer
1 system per app
Max 5 TFs, Max 50 items"]
    M3 -->|NO| M4{Surgical Instruments?}
    
    M4 -->|YES| SURGICAL["SURGICAL INSTRUMENTS
Same manufacturer, same risk class
Same function
Max 5 TFs, Max 50 items"]
    M4 -->|NO| M5{Dental Instruments?}
    
    M5 -->|YES| DENTAL["DENTAL INSTRUMENTS
Same manufacturer, intended use
Same specialty
Max 5 TFs, Max 50 items"]
    M5 -->|NO| M6{Same intended use, risk class,
GMDN code, design, material?}
    
    M6 -->|YES| FAMILY["MEDICAL DEVICE FAMILY
Same device family
Max 5 TFs, Max 50 items"]
    M6 -->|NO| SEPARATE
    
    IVD_START[IVD Pathway] --> IV1{Class A exempt?
Specimen containers, stains,
reagents, culture media}
    IV1 -->|YES| EXEMPT["CLASS A EXEMPT BUNDLE
Different intended uses allowed
Max 50 items total"]
    IV1 -->|NO| IV2{Same legal manufacturer?}
    IV2 -->|NO| SEPARATE
    IV2 -->|YES| IV3{Same risk class?}
    IV3 -->|NO| SEPARATE
    IV3 -->|YES| IV4{Same intended use +
same principle of operation?}
    IV4 -->|NO| SEPARATE
    IV4 -->|YES| IV5{One of 7 groupings?
Blood, Tissue, Cancer, Genetic
Infections, Non-infectious, Controls}
    IV5 -->|NO| SEPARATE
    IV5 -->|YES| BUNDLE["STANDARD IVD BUNDLE
Shared performance data = 1 TF
Max 5 TFs, Max 50 items"]
    
    PACK --> CHECK
    SYSTEM --> CHECK
    SURGICAL --> CHECK
    DENTAL --> CHECK
    FAMILY --> CHECK
    EXEMPT --> CHECK
    BUNDLE --> CHECK
    
    CHECK{"Limits Check
Items ≤ 50?
TFs ≤ 5?"}
    CHECK -->|YES| SUCCESS["SUCCESS: Single MDMA application"]
    CHECK -->|NO| WARNING["WARNING: Split into multiple apps"]
    
    SEPARATE --> END1["Submit separate applications"]
    SUCCESS --> END2["Submit bundled application"]
    WARNING --> END3["Revise bundling strategy"]
